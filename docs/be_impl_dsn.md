## 一、OpenAI 兼容节点

### 1.1 聊天补全 `POST /v1/chat/completions`

#### 实现步骤

1. **解析请求**：校验 Content-Type 为 `application/json`，解析请求体
2. **认证校验**：若 `api_key_enabled=true`，校验 `Authorization` 头中的 API Key
3. **模型映射**：查询 `model_mappings` 表，将 `model`（虚拟名）转换为实际模型名
4. **查找健康节点**：查询 `nodes` 表中 `enabled=true AND healthy=true` 的节点，筛选 `node_models` 中包含实际模型的节点
5. **随机选择节点**：从候选节点中随机选择一个
6. **转换请求**：将 OpenAI 格式转换为 Ollama `/api/chat` 格式
7. **转发请求**：调用 Ollama 节点
8. **转换响应**：将 Ollama 响应转换为 OpenAI 格式
9. **记录日志**：写入 `request_logs` 表
10. **返回响应**：流式返回 SSE 或非流式返回 JSON

### 1.2 查询可用模型 `GET /v1/models`

#### 实现步骤

1. **查询虚拟模型**：从 `model_mappings` 表获取所有映射，构建虚拟模型列表（`owned_by="ollama-proxy"`，附加 `x-actual-model`）
2. **查询真实模型**：从 `nodes` 表获取所有健康节点，从 `node_models` 表去重获取模型列表（`owned_by="ollama"`）
3. **合并结果**：虚拟模型和真实模型均返回，虚拟模型优先
4. **格式化响应**：按 OpenAI `/v1/models` 格式返回

#### 流程图

```
┌─────────────────────────────────┐
│       GET /v1/models            │
└─────────────────────────────────┘
                │

                │
                ▼
    ┌───────────────────────┐
    │ 构建虚拟模型列表       │
    │ owned_by=ollama-proxy │
    │ + x-actual-model      │
    └───────────────────────┘
                │
                ▼
    ┌───────────────────────┐

    │ (enabled+healthy)     │
    └───────────────────────┘
                │
                ▼

    │ 查询 node_models      │
    │ 去重获取真实模型列表   │
    └───────────────────────┘
                │

                │

    │ 合并虚拟+真实模型      │
    └───────────────────────┘
                │
                ▼
         返回 200 响应
```

### 2.1.1 登录 `POST /api/login`

#### 实现步骤

1. **解析请求**：校验请求体包含 `password` 字段
2. **验证密码**：与 `config.ADMIN_PASSWORD` 比对
3. **创建 Session**：生成 session_id，存储到服务端 session 存储
4. **设置 Cookie**：响应中设置 session cookie
5. **返回结果**：成功返回 `{code: 0}`

### 2.3.2 创建/更新映射 `POST /api/mappings`

### 4.4 URL 格式校验

```python
from urllib.parse import urlparse

def is_valid_url(url):
    try:
        result = urlparse(url)
        return all([result.scheme, result.netloc])
    except:
        return False
```
